## Contributions and dependencies

Contributors must submit work they have rights to contribute, disclose relevant third-party code and preserve upstream notices. This repository does **not** currently assert a copyright assignment or signed Contributor Licence Agreement. Review [CONTRIBUTING.md](CONTRIBUTING.md) for the contribution process.

Third-party components (including optional `PyJWT[crypto]`, web `next` and `next-auth`, infrastructure images and GitHub Actions) have their own licence and attribution requirements. A dependency version pin is not a licence audit. Before public/commercial packaging, produce and archive an SBOM/notice report and review incompatible or unknown licences.
